# 轻小说对话辅助阅读器

当前版本：`0.2.0`。

本地运行的轻小说阅读与对白标注工具：用大语言模型识别说话人，以颜色和人物标签辅助阅读，并支持人工确认与修正。

## 重点功能

- 导入 TXT / EPUB，保留章节、段落、注音和本地插图，自动检查章节和引号问题。
- 自动识别章节人物和对白归属，按人物着色；支持人物编辑、手动合并及模型合并建议预览与确认。
- 单章可选择多个窗口处理；批量可按章节范围后台处理，查看实时进度、设置并发及 Token 上限。
- 可开启阅读时自动处理当前章及后续章节，边读边准备后文。
- 待确认队列、人工更正和局部模型复核，人工确认结果优先。
- 自动保存阅读位置，支持段落书签、初读 / 重读显示及阅读偏好。
- 导出带标注的 EPUB / HTML；本工具导出的 EPUB 回导可恢复可见标注和已处理章节状态。

## 安装与启动

环境：Windows 10/11、Python 3.11+、[uv](https://docs.astral.sh/uv/)、Node.js 22 / npm 10。

克隆仓库后，在项目根目录运行：

```powershell
uv sync --project backend --all-groups
Push-Location frontend
npm ci
Pop-Location
```

双击 `start.bat`，启动脚本会执行数据库迁移、构建前端并打开 <http://127.0.0.1:8765>。

停止服务：双击 `stop.bat`，或在启动窗口按 `Ctrl+C`。更换端口可运行 `.\start.bat 8800`。

## 快速使用

1. 在书架导入书籍，到“模型配置”填写 API 地址、模型名称和密钥，并测试连接。
2. 打开“预览与处理”，选择单章或批量，设置模型、处理范围和额度。
3. 单章先识别并确认人物，再处理对白；批量先查看 Token 预估，再确认启动。
4. 返回阅读，检查人物标签；通过待确认队列修正结果，按需导出。

## 使用前须知

- 模型推理会把相关正文发送到所配置的提供方，可能产生费用；识别结果仍需人工复核。
- 书籍与运行数据默认保存在本机 `data/`，升级前建议备份；不要提交密钥或运行数据。
- 后台批量处理支持应用内切换页面，但刷新或关闭页面后不会自动续接调度。
- 复杂 EPUB 排版不保证完全还原；当前面向本地单用户，没有云端同步。
