# 处理策略怎么选

本页解释“预览与处理”“通用设置”和局部复核中的共用策略选择。完整页面操作见[用户指南](USER_GUIDE.md)。

## 不确定时怎么选

- 质量优先：选择“对话块：辅助隔离与独立复核”，复核次数至少为 1 时显示“推荐·质量优先”。它结合连续原文、无效辅助信息隔离和全窗独立复核；复核次数为 0 时只提示“需开启复核”，不会自动加次数。模型支持时可另行选择高思考，不会随推荐自动开启。
- 减少附加调用：选择“对话块：简短归属［较省用量］”。标签仅指相同输入与模型下省去独立复核、人物反馈等附加调用；不代表全局 Token 最少，常规复核仍按复核次数执行，重试、思考及章节长度也影响总消耗。
- 想继续使用较小窗口及预算内的精选原文：选择“分窗处理：精选上下文［默认·小窗口］”。这是默认值，已有偏好不会被推荐覆盖。
- 怀疑人物名单有遗漏：可尝试带“额外人物检查”的方案，但它每窗额外调用模型，目前未证明有稳定质量收益，不能因为步骤更多就当作更准确。
- “短范围·不分窗”适合能一次放入上下文的范围；超限时需缩小范围，不自动拆窗。

推荐基于目前有限样本和流程能力，不是所有书籍、模型的准确率保证。全部完整原文方案仍属试验策略，其他标签说明功能与适用范围，不是准确率排名。界面只帮助选择，不修改默认策略、思考设置、复核次数或运行中的任务。

## 白话区别

| 选项组 | 模型能看到什么 | 使用边界 |
| --- | --- | --- |
| 分窗处理：精选上下文 | 较小窗口中的对白，以及预算内挑选的邻近原文 | 默认策略；小窗口 |
| 完整对话块 | 当前窗口的连续完整原文；整章能放下时一次处理，长章按完整段落与连续对白分窗 | 试验策略；单个完整块仍过长会提示，不截断对白 |
| 其他完整上下文方式 | 所选范围的连续原文 | 试验策略；范围超限时需要缩小范围 |

“完整对话块”按段落、连续引语及分隔标记组织，不代表模型已经确认了场景。初读不使用窗口之后的原文和未来身份资料；重读可参考允许范围内的后文。

下拉框用“对话块：…”和“完整上下文：…”区分两组。简短摘要显示当前范围、试验性质和额外调用风险；需要了解细节时展开“策略区别与使用说明”。展开或收起说明不改变已选配置。

## 附加能力与费用

- 简短归属：模型主要输出人物、类型和证据，编号及覆盖检查由程序完成。
- 辅助信息隔离：受话人物等辅助信息不合法时隔离它，保留不依赖该信息的有效归属；不是放宽人物证据要求。
- 独立复核：每轮检查窗口全部目标，出现分歧可能额外裁决与核验。次数为0时关闭；每个额外调用都可能增加用量和等待，不保证一定纠正错误。
- 人物名单反馈：额外检查遗漏或身份问题，需要至少1次复核；不会直接修改全书人物或第一视角。
- 人物证据定向修复：单独开启，保留有效人物组，仅修复证据不合法的相关组。人物分析仍查本章全文，与所选对白窗口无关。

选择策略不会自动开启模型思考、提高输出上限或修改已启动任务。单章、批量、自动处理和局部复核共用策略；人物定向修复不用于人物合并或局部对白复核。处理页参数会记住；通用设置中的草稿仍须点击“保存阅读与处理设置”。

## 界面标识

协议和凭据模式以中文显示，模型名称及服务地址保留服务商原值，便于正确填写。标注状态区分“已自动接受”“已人工确认”“暂定，待确认”和“尚未确定”；自动接受不等于人工已确认，也不保证模型判断正确。技术标识可在悬停或可展开的说明中查看。
