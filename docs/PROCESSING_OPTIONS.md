# 处理策略怎么选

默认使用“分窗处理：精选上下文”。先在“通用设置 → 试验功能”开启并保存，才会在“预览与处理”“通用设置”或局部复核中显示完整上下文等试验策略。关闭试验功能后，新任务使用默认策略；已启动任务及恢复、重试保持原配置。完整页面操作见[用户指南](USER_GUIDE.md)。

## 先选适合你的方案

- 拿不准时：选带“推荐·质量优先”标签的方案，并把复核次数设为至少 1。模型结合完整原文判断说话人，再检查窗口里的全部对白。
- 想减少用量：选“对话块：简短归属［较省用量］”，少做独立复核、人物检查等额外步骤。常规复核仍按你设置的次数执行。
- 想按小段处理：选“分窗处理：精选上下文［默认·小窗口］”，每次处理一小段对白，并参考附近的原文。
- 怀疑漏掉人物或认错身份：选带“额外人物检查”的方案。每窗多调用一次模型，需要至少 1 次复核；建议和理由可在任务详情查看。
- 只处理一段较短的内容：可选“短范围·不分窗”方案。它一次处理所选原文，范围太长时需要缩小范围。

复核次数越多、思考越深入，通常用量和等待也会增加。需要更细致的判断时，可在思考设置中选择模型支持的思考强度。

## 各类方案如何处理原文

| 选项组 | 处理方式 |
| --- | --- |
| 分窗处理：精选上下文 | 分小窗口处理，参考附近原文 |
| 完整对话块 | 按完整段落和连续对白分窗，每窗尽量不超过 128 个待处理目标 |
| 其他完整上下文方式 | 一次处理所选范围，太长时请缩小范围 |

初读只参考当前窗口及前文，重读可参考处理范围内的后文。一个完整段落仍太长时，界面会提示缩小范围。

128 是软限制：一段连续对白不会被强行拆开，原文长度仍受窗口预算限制。新任务使用此分窗方式；已有任务的窗口不变。

## 标签和附加功能

- **推荐·质量优先**：结合完整原文、保留可用结果和独立复核。复核次数为 0 时显示“需开启复核”。
- **较省用量**：减少独立复核、人物检查等额外步骤。实际用量也会随章节长度、思考和重试变化。
- **辅助容错**：对白是在对谁说等辅助信息有问题时，保留不受影响的对白结果；需要核对的相关对白放入待确认队列。
- **全窗复核**：每次复核检查窗口全部对白，有分歧时会再调用模型检查；仍无法判断的对白留待你确认。
- **额外人物检查**：检查遗漏人物、身份或第一视角问题。需要调整主人公时，请回到本章人物确认。
- **人物证据定向修复**：在人物分析中单独开启。保留已通过检查的人物，仅重新处理有问题的人物；人物分析始终查看本章全文。

单章、批量、自动处理和局部复核共用策略选择。修改后从新任务开始生效，正在运行的任务保持原设置。处理页会记住参数；通用设置中需点击“保存阅读与处理设置”。人物定向修复不用于全书人物合并或局部对白复核。

## 状态怎么看

术语、强调词、修辞说明、泛指的社会观念和没有具体表达者的假想台词，不要求归属给人物。真实或特定人物的原话引用仍需判断来源；不能把找不到说话人的句子一律当作非人物文本。

“人物归属有分歧”表示复核没有确认人物归属，不等同于分数低。这类对白仍需核对，旧记录也按此名称显示。

“已自动接受”表示程序已保存模型结果，“已人工确认”表示你已经确认过；“暂定，待确认”和“尚未确定”表示仍需核对。技术详情可在悬停说明或展开区域查看。

完整对话块等简短归属方案会先按设置次数纠错。纠错后仍有个别对白的证据或人物字段不合格时，保留其他有效归属；异常句中能识别的候选人物会暂定显示，并以“模型结果校验警告”进入待确认队列。已有候选和声明、身份依据通过校验的新人物都可以暂定显示。没有可用人物的句子显示为尚未确定。重复或遗漏的对白也会留待确认。候选不是已确认结果，可在阅读中点击对白核对。在通用设置的“阅读显示”开启并保存“显示待确认对白标记（⚠）”，即可为所有待确认对白显示标记；默认关闭。

未发送的对白、场景结构错误、无法读取的结果等仍会使窗口失败；不会借容错创建缺少有效声明或身份依据的新人物。精选上下文的原有长格式流程仍沿用原校验方式。已有失败任务不会自动重发，可手动重试。

简短归属方案纠错时，会保留同一窗口前次结果中有合法证据、不受本次变化影响的归属，避免一次纠错丢掉其他正确结果。不能安全保留的部分仍会警告；每次实际模型调用照常计量。已有待确认项不会批量删除，重新处理得到有效结果后，相应的自动待确认原因才会解除。
