# 用户使用指南

本指南按页面介绍操作。安装与启动见 [README](../README.md)。免安装版完整解压后双击 `NovelDialogueReader.exe`，不要单独移动 EXE 或删除配套文件夹。

## 第一次使用

1. 在“书架”导入 TXT 或 EPUB，即可阅读原文，不必先调用模型。
2. 在“模型配置”添加自己的模型服务，测试连接并保存。
3. 打开书籍的“预览与处理”，先尝试单章，再按需批量处理。
4. 回到阅读页查看人物标注，在对白详情或“待确认队列”中修正不确定结果。
5. 需要在其他阅读器中阅读时，从“导出”生成 EPUB 或 HTML。

按钮不可点击时，先查看旁边的提示或悬停说明，按提示补齐条件。长列表可用标题右侧的上下箭头收起或展开；收起不会停止任务或丢弃编辑。

## 任务队列页

从顶部“任务队列”进入，与书架、模型配置和通用设置同排。这里可跨书籍查看已添加的处理范围和后台模型任务，展开范围可查看人物识别及各对白窗口的状态；“查看任务”打开用量、进度、错误和恢复操作。默认只显示等待或执行中的任务，勾选“显示已结束任务”查看历史记录。

停止批量范围不会把已经完成的任务改成已停止。新批次开始后，旧范围仍保留各任务的状态和详情入口。旧范围若未保存完整明细，会显示“状态待核实”；展开“本章后台任务”查询实际任务，再点击“查看任务”处理恢复。该查询可能包含本章其他批次的尝试，不会调用模型。预览与处理的批量明细也提供“查看任务”入口。

提交单章、批量或自动合并分析后，可以继续选择其他章节、窗口或书籍。同一章节的同一窗口已经等待或执行时会提示重复；请选择其他窗口，或先在队列停止原范围。各范围保留提交时的模型与处理参数，同一本书的范围依次执行，不同书籍可共享当前页面的并发额度；人物识别仍逐章进行。

“取消范围”不再派发该范围；“停止范围”停止后续窗口，等待已发出的请求收尾。已提交的模型请求仍可能计费，已保存的结果保留。保持应用页面打开才能继续派发等待范围；切换页面和刷新可恢复队列，关闭全部页面后尚未派发的范围暂不继续。后台已接收的任务会继续执行。

本浏览器的范围记录与服务端任务分开展示；换浏览器仍能查看后台任务，但不能恢复原浏览器中尚未派发的范围。结果未知的请求不会自动重发，需要先在详情核实。

## 书架页

顶部导航点击“书架”，查看全部已导入书籍。

### 导入书籍

1. 选择或拖入 TXT、EPUB 文件。
2. 可填写书名；留空时使用文件中的书名或文件名。
3. TXT 编码通常保持“自动检测”。若出现编码错误，按候选和文字预览重新选择。
4. 点击“开始导入”，等待完成。可以直接阅读，或点击“检查预处理结果”检查目录与引号。

EPUB 会尽量沿用原书的卷、章目录，保留插画。明确列在目录中的彩页等纯图片章节可以单独显示；没有正文的章节无需调用模型，会自动记为已完成。复杂排版不保证与原阅读器完全一致。

文件超过上限时，到“通用设置 → 应用配置 → 导入与EPUB安全限制”调整容量，保存并重启后再导入。格式损坏时，请先检查或修复原文件，不要只提高容量上限。

### 阅读与删除

点击“开始阅读”打开书籍。开启自动续读后，会回到最后阅读的位置；同名书籍可用导入时间区分。

删除时，核对确认框中的书名和导入时间。删除会一并移除本书的标注、人物、书签、阅读位置和任务记录，应用内不能撤销；不会删除你最初选择的外部原文件，也不影响其他同名书籍。重要资料请先导出或备份。本书仍有任务时，先停止并等待结束再删除。

## 阅读页

从书架进入。页头可跳转到本书的“预览与处理”“全书人物”“待确认队列”，或打开导出窗口。

### 切换章节与查看进度

- 左侧“目录”按卷分组，卷可以展开或收起；点击章节名跳转。
- 阅读区右下角的“上一章”“下一章”按目录顺序切换。
- 彩色圆点区分未处理、排队中、正在识别人物、正在处理对白、已完成及失败/已停止。对白处理显示窗口进度 `x/y`；卷名旁的圆点和数字汇总各状态的章节数，悬停可查看说明。
- 失败或已停止章节旁的重试图标用于补齐该章失败、取消的任务，不重复处理成功窗口。排队或执行中的章节旁有取消图标，只停止该章，不影响其他章。

取消后需要等待已发出的请求收尾，不能保证模型服务立即停止计费。

### 人物标注与阅读模式

正文上方可切换候选引语和人物标注的显示。悬停人物名字或已标注对白，可查看人物说明；点击对白打开详情。

已指定人物的心声与对白使用同一人物颜色、姓名标签和格式，也可悬停查看说明、点击更正。嵌套引号内已有的标注也会显示。尚未指定人物的心声不会自动猜测人物或着色；初读中尚未揭示的身份仍暂不显示。

- **初读**：尽量不显示后文才揭示的人名、身份和说明，适合第一次阅读。
- **重读**：显示最终确认的资料与归属，适合回顾。

两种模式只改变展示，不重新调用模型或生成两套结果。原文、全书人物管理及模型判断仍可能包含剧透；旧资料缺少早期记录时，初读中的信息可能较少。

### 查看或更正对白

点击对白查看原句、上下文、当前归属和判断依据。按实际情况选择已有说话人、新建说话人、锁定为未知，或修改类型，再点击“确认更正（不调用模型）”。指定人物时可选择对白、心声或人物原话引用，不会强制改成实际发声；在这三类之间修改类型会保留已有归属，没有人物时不会自动猜测。改为集体声音、非人物文本或表达类型待确认会清除单个人物归属；只想清除归属而保留类型，可选择“锁定为未知”。已有说话人的选项可悬停查看说明。

也可以标记为待确认、延后处理，或撤销刚才的更正。人工锁定的归属不会被后续模型任务自动覆盖。

需要模型再次判断时，展开“局部复核”，选择模型、思考设置及额度后启动。局部复核消耗 Tokens；遇到超时或结果不明确，先查看任务提示，不要连续重复提交。

### 阅读位置与书签

切换章节和滚动会自动保存最后阅读位置。手动书签与阅读位置相互独立。

每个非空正文段落旁有一个 ☆ 按钮，鼠标悬停或键盘聚焦时显示，触屏直接显示。点击可收藏该段并填写备注；标题、图片和空段落没有此入口。

左侧与“目录”同级的“书签”标签可以查看、跳转、编辑或删除书签，也可进入独立书签页管理。

每次点击“跳转阅读”都会定位到书签段落。滚动离开或切换章节后，再点同一书签也能重新定位。

## 预览与处理页

从阅读页进入时，默认带入正在阅读的章节；返回“去阅读”时回到此前的阅读章节。先选择“单章处理”或“批量处理”，再配置对应范围。

### 共用配置

在“模型配置与本次思考设置”中选择模型，以及沿用默认、关闭、开启或自适应思考。是否支持这些选项取决于模型服务，不确定时先沿用模型配置。

模型、思考、复核、重试、并发及额度等常用配置会记住，并在相关处理操作间共用。不同浏览器或服务地址不共享这些偏好。

“对白处理策略”默认使用“分窗处理：精选上下文”。质量优先可选“对话块：辅助隔离与独立复核”，减少附加调用可选“对话块：简短归属”；推荐条件与用量边界见[处理策略选择](PROCESSING_OPTIONS.md)。完整策略保留所选范围的连续原文，不拼接不同章节；范围过长会明确提示，不静默截断。独立复核每轮检查全部目标，分歧时可能再进行裁决和核验；复核次数为 0 时关闭。思考模式和强度可在思考设置中另行选择。单章、批量、自动处理和局部复核共用选择，只影响之后创建的任务，人工锁定仍保留。

长章可在完整对话块组选“对话块：简短归属”，或选择带独立复核、辅助隔离等能力的版本；区别与费用见[处理策略选择](PROCESSING_OPTIONS.md)。整章能放下时仍一次处理；超限时按完整段落与连续对白分窗，不按固定对白条数切分，同时保留相邻段落作为边界参考。初读只使用窗口之前的边界原文，重读可参考同一处理范围内后面的相邻段落。如果单个完整对话块仍太长，会提示缩小范围，不截断对白。人物分析仍查整章，旧任务不会切换到新分窗方式；它仍是试验策略，不保证归属更准确。

需要单独处理无效受话信息时，可选择“对话块：辅助信息隔离”，或“对话块：辅助隔离与独立复核”。模型可以提供辅助信息，但不要求每句都提供。辅助信息不合法时，不依赖它的有效归属保留，依赖它的对白及关联身份转为待确认，并在任务详情显示提示。主归属仍须通过完整校验，隔离本身不增加模型调用；开启独立复核仍会消耗额外 Tokens。默认策略、旧任务和已有标注不变，这不代表已经证明准确率更高。

“对话块：人物反馈与独立复核”每窗额外调用一次模型，检查是否遗漏人物、人物关联有争议或第一视角有问题。必须把“每个窗口最多复核次数”设为至少 1，否则不能启动；系统不会替你增加次数。反馈只是候选，之后独立复核与必要的裁决、核验仍可能增加消耗；估算已包含反馈，但不是费用上限。任务详情的“人物名单反馈”可展开查看中文分类和理由。第一视角建议不会自动修改本章主人公，需查看原文后在本章人物确认中调整。已有任务不会切换策略，旧偏好不会自动开启这一额外调用；它仍在效果评估中，不保证更准确。

“启用人物证据定向修复（试验）”默认关闭，单章、批量与自动处理共用。开启后保留证据校验有效的人物，仅对不合法的相关人物组调用模型修复；最多修复次数为 0 时不修复，最多 5 次。首次人物分析的格式重试沿用“校验失败后的重试次数”；修复输出不合法也消耗修复次数，不额外追加重试。该功能仍需质量评估，合法证据不代表身份判断一定正确。额外阶段会增加消耗和等待，批量估算只是规划参考，不是费用上限。修改仅影响新人物任务，刷新及重试沿用原任务配置；通用设置里的修改需保存，不用于全书合并或局部对白复核。

新建任务的修复会保留独立修好的人物，后续只重试仍有问题的部分。没有依据的辅助说明会移除，不因此丢掉有效身份；同一人物相关的身份问题仍要整组检查。“人物分析提示”显示修复与未解决数量，展开可看每次修复记录。次数用完后仍请核对保留名单，补充遗漏人物并选择主人公；程序不会替你随意指定主人公。旧任务继续按创建时的处理方式恢复。

单章切换策略后会重新预览窗口；批量需重新估算。正在运行的批次使用启动时的策略，不接受另一种策略估算的追加窗口。通用设置中的策略选择需保存后生效，处理页中的选择沿用参数记忆方式。局部复核仍只处理服务端选定的当前场景或章节，不因选择完整策略而扩大范围。

| 配置 | 如何使用 |
| --- | --- |
| 每个窗口最多复核次数 | 首次有效处理后的额外检查轮次，0 关闭。每轮检查窗口全部对白，不只检查待定项；人工锁定结果不覆盖。一轮可能产生多次模型调用。 |
| 校验失败后的重试次数 | 对白输出无效时的额外尝试次数，0～5，默认 1，不含首次调用。启用人物证据定向修复时，也用于首次人物分析的格式重试；不替代人物证据修复次数。 |
| 最大并发任务数 | 同时执行的任务数，1～16。设为 1 按顺序处理；提高并发会增加同时发出的请求。 |
| Token 上限 | 留空不设本次额度限制。单章区分输入与输出上限，批量按累计消耗限制；仍受模型服务的输出上限和余额限制。 |

估算和窗口预览不调用模型；人物分析、试运行、正式处理、额外复核和纠错重试会产生用量。估算不是最终账单，实际消耗可能更高，失败请求也可能计费。

### 单章处理

1. 选择章节和处理范围，查看窗口列表、对白数、文字预览和 Token 估算。
2. 分析并核对本章人物：检查姓名、说明和已有全书人物关联，勾选本章出现的人物，选择“本章第一视角主人公”，确认名单。
   也可以不调用模型，直接“手动添加人物”。填写姓名、别名和说明，勾选本章出现并选择主人公后，点击“确认人物与主人公”保存；刷新或再次进入仍保留已确认的名单。取消勾选的人物不进入本章已确认名单，但不会删除全书人物。
   未确认的手动编辑会在同一份名单下记忆，刷新或切换章节不会串到别章。重新分析成功后以新的候选名单为准，请先保存需要保留的编辑；分析结束后无需再次调用模型来读取已保存的结果。
3. 勾选需要处理的窗口。可以选择不连续的多个窗口；默认优先选未完成窗口，也可以只选失败窗口。
4. 如需检查模型效果，使用“试运行预览（调用模型）”。确定范围后点击“按此范围正式处理”。

人物分析始终查看整章，窗口勾选只限定对白范围。窗口旁标明完成情况，补齐剩余窗口后可完成整章。若所有窗口已完成但目录未同步，可使用“同步章节完成状态（不调用模型）”。

新建人物分析只带入本章末尾以前可见的人物资料；新建初读对白任务按本次发送的原文范围限制人名、别名和说明，额外复核也遵守这一范围。没有早期记录的旧人物资料可能暂不显示在模型输入中，注意检查遗漏人物；这不会删除或修改全书人物资料，也不能保证模型不会自行推测后文身份。已创建的旧任务按原流程恢复，不会因此自动重新调用模型。

本章只使用简称或称呼时，已识别的人物可以继续显示之前确认的正式姓名，不要求本章再次写出全名。发现新姓名仍需本章原文依据。旧提案因本地校验失败但已保存完整返回时，可从任务详情恢复重新校验，不增加模型调用；恢复后仍需核对人物名单。

人物分析会先对照已有人物。对于店长等有具体任职信息的人物，程序还会核对本章和前文的身份说明，一致并唯一指向已有候选时复用该人物，避免因发生了不同事情就重复新增。老师、女同学、店员等可能有多人的称呼仍需模型辨别；只有称呼相同、候选有歧义或可能换人时不会强行合并。已有重复人物仍需在全书人物页查看合并建议后处理。

新的人物分析会分别检查姓名、别名与说明的正文依据。某个人物的身份依据无效时会隔离该人物，保留其他有效提案；只有辅助说明或关系信息有问题时会移除该信息。如果整份提案都没有有效人物，分析仍会失败。“人物分析提示”显示隔离与移除数量，可展开查看详情；人物任务详情也提供该提示。请检查保留名单，必要时手动添加遗漏人物。这些候选不会因为通过校验就成为人工确认人物；有相同称呼不代表是同一个人，未知姓名也可以使用可区分的简短称呼。

处理后查看“单章窗口任务进度”。“查看任务”会定位到对应窗口详情，显示状态、用时、错误及恢复操作，不会重新调用模型。

### 批量处理

1. 选择开始和结束章节，检查模型、复核、重试、并发和 Token 上限。
2. 默认跳过已处理章节；需要重做时勾选“强制重做已处理章节”，并用章节范围限制重做范围。重做再次消耗 Tokens，但保留人工锁定的对白标注。
3. 点击“预估 Token”，查看整批估算。
4. 点击“确认并开始批量处理”。

人物识别按章节顺序执行，后章沿用前章已识别人物，同时查找新人物。已确认章节的对白窗口可与下一章人物识别同时进行。

单章失败不会让所有后续章节停止。没有正文的章节不消耗模型 Tokens；有正文但识别失败的章节仍需检查。

### 进度、停止与恢复

运行期间进度面板显示章节、人物识别或对白归属、窗口编号及状态，配置区仍可用于添加其他范围。可进入阅读页继续阅读，或在顶部“任务队列”跨书籍追踪；只阻止重复提交已经排队或执行的同一窗口。

- “停止批量处理”停止派发新任务，等待在途请求收尾，保留已保存结果和实际用量。
- 在任务列表的“原因 / 错误详情”查看问题。“查看任务列表”会展开并定位明细。
- 可以连续点击不同失败窗口的重试按钮，或阅读目录里不同失败章节旁的重试图标。任务加入同一个队列，有空闲并发位置时立即处理，满额时排队；不必等前一次重试结束。成功窗口不重复处理，重试沿用原模型设置和剩余额度。人物识别仍逐章进行，正在停止或结果尚不明确的任务需先查看详情。
- 刷新或重新打开同一浏览器、同一服务地址时，可以恢复已保存队列并接回已有任务，不会因此重做已完成部分。关闭所有页面时，尚未派发的任务暂不继续。
- 在同一浏览器、同一服务地址的另一个标签页阅读时，批量进度也会同步；章节完成后目录及时更新，不必等整批结束。窗口正在调用模型或复核时显示处理中，不再误显示排队。

已停止、额度耗尽或结果不明确的任务不会自动重试。服务重启后若提示请求结果未知，先检查详情，再按提示恢复。换浏览器、清理浏览器数据或更换书籍版本后，未派发队列可能无法恢复；已有标注仍保留。

人物分析若已收到模型返回，但保存阶段中断，可在任务详情点击“恢复已返回的人物结果”，无需再次调用模型。已知用量会保留；缺少完整返回时会提示先核对，确认重发才会再次调用。

### 用量与额度

用量区分别显示本次与累计消耗。批量累计包含人物识别、对白处理、复核及已知的失败调用用量；未上报的用量另作提示，不按零消耗处理。

接近额度上限的 80% 时会提醒。修改额度大小会继续当前任务，不重新开始，也不清零累计消耗；按照提示刷新额度只重置额度计数。达到上限，或设置了上限但模型用量未知时，处理会停止，请先检查再继续。

## 全书人物页

从本书导航进入。本页展示全书已识别人物，可能包含后文身份，初读时注意剧透。

人物按出现章节数、对白数优先排列，可按姓名、别名或说明搜索。统计只涵盖已识别内容。来源标签区分模型识别、批量自动确认、人工确认和导入恢复；自动确认不表示你已人工检查。

### 修改人物与颜色

批量识别优先使用有原文依据的完整姓名，后续简称仍作为别名。人物说明尽量来自已验证的说明事实；缺少依据时可能留空，不会为了补齐而猜测。颜色帮助及整本书的编辑锁定原因统一显示在页面上，卡片保留各人物自己的保存状态和错误。

- 编辑姓名、别名、说明，点击“保存人物资料”。别名用“、”分隔。
- 修改前选择“本次人物修改从哪一章起可见（初读）”，避免提前展示后文身份；不确定时使用默认的全书末尾。
- 选择“人物颜色”，查看效果后点击“保存颜色”。选择“自动分配”可恢复自动配色；颜色由程序生成，不由模型决定。

改色不调用模型，初读和重读均生效。先保存未完成的人物资料编辑，再改色。人物很多时颜色可能接近，建议保留人物标签辅助辨认。

### 手动合并

选择“合并到全书人物”的目标，点击“合并人物…”，核对后确认。用于整理同一个人的不同称呼或重复记录；同名不一定是同一人。

合并不能自动撤销，重要资料请先备份。人工确认不是永久锁死资料，你仍可更名或接受合并建议。

### 自动合并建议

1. 展开“自动合并人物（先预览，再确认）”。
2. 选择模型和思考设置，按需填写本次 Token 上限。
3. 勾选同意调用模型，点击“分析合并建议”。
4. 核对保留人物、并入人物、名称、整理后的说明及合并依据。
5. 勾选需要接受的组，点击“确认合并所选”；不接受则“放弃本次建议”。可以一次选择多组。

分析消耗 Tokens，但只生成建议，不立即改人物。确认或放弃不再调用模型，未选中的人物保持不变。建议也可能只包含更名，例如把已有真实姓名的“女神”改为“阿库娅”。模型可能漏找或误判，请检查依据和说明。

本书任务运行中不能分析或执行合并。有待确认建议时，先确认或放弃再重新分析；修改资料后旧建议可能失效。刷新后可找回已有建议，但需要重新勾选。

## 待确认队列页

从本书导航进入，集中检查无法确定说话人、证据不足、置信度低或场景边界等问题。

阅读页与待确认详情中的人物归属、已有说话人选项统一显示姓名或已有代称/说明，不要求记住场景编号。缺少人物资料时显示“尚未确定人物”；非人物文本显示“无需归属”。人物选项的悬停提示保留说明。

“表达类型待确认”表示暂时无法区分对白、心声或其他文本；“引用来源待确认”表示人物原话的原表达者不明，不等于真实对白的说话人未知。术语、章节标题、强调词、译者注等应归为“非人物文本（无需归属）”，不会仅因没有说话人进入队列。人物原话引用仍需判断人物，不能把证据不足的对白全部归为非人物文本。

旧标注不会自动改写；旧待确认项的原因说明会兼容调整。发现术语或注释被标为引用时，可在详情选择“修改类型 → 非人物文本（无需归属）”，点击“确认更正（不调用模型）”，该句的待确认项随人工更正解决。模型重新处理使用新的分类规则，不自动清除用户主动标记，也不保证分类完全正确。包含新原因的导出书籍请用支持这些原因的版本回导。

1. 按章节、原因、状态筛选。
2. 列表显示实际原句、中文原因和状态；同一句有多个原因时合在一项查看。
3. 点击“查看并确认”，结合上下文修正归属或类型，也可延后处理。
4. 场景边界问题使用“处理场景边界”中的选项。

人工更正不调用模型；展开局部复核才会调用模型。置信度低不是准确率百分比，也不一定意味着归属错误。延后的对白可在“已跳过（延后）”中找回，已处理项可在“已解决”中查看。

改单句、修改类型或撤销单句更正只影响该句；多选更正只影响选中的对白，不会因为同一人物或同一处理窗口就要求其他对白重新确认。人物拆分、场景边界调整等仍可能让实际受影响的对白需要复核。

若旧队列积累了改单句后连带产生的记录，可点击“清理历史误触发的重新确认”。清理针对本书全部章节，不改变原人物归属、不调用模型、不删除记录；真正的未知、低置信度、用户标记、已延后、结构调整和无法核实来源的记录保留。任务结束或停止后才能清理，完成后会显示清理与保留数量。

## 书签页

可从阅读侧栏“书签”进入独立管理页。

- “跳转阅读”回到收藏的段落。
- 编辑备注后点击“保存备注”。
- “删除书签”只移除该书签，不删除正文或阅读位置。
- 书签较多时使用“加载更多书签”；读取失败可重新读取。

书签不会随最后阅读位置变化。原文版本更换后，旧书签可能无法跳转；删除书籍会一并删除书签。书签目前不随 EPUB 导出和重新导入迁移。

## 书籍预处理页

导入完成后点击“检查预处理结果”，或从“预览与处理”点击“打开预处理”。只有目录或引号存在问题时才需要使用，不必每次处理前都操作。

### 章节名与边界

查看章节列表及修复建议，可以改名、合并误分章节，或重新检查建议。

合并不能自动撤销。已有标注、人物名单或完成状态的相邻章节不能合并，此时可改名，或重新导入原文件后检查。重新导入不会把旧版本的标注和书签自动迁移到新版本，请先备份。

### 引号修复

展开记录，对照原文和修复预览调整闭合位置。可点击原文定位，按字或标点前后移动，移到段尾，或调整、停用修复；确认后点击“保存并重扫”。

预处理不调用模型，也不改写原始小说文字。本书有运行、排队或待恢复任务时，先处理任务再修复；保存冲突时重新读取后核对。

## 模型配置页

顶部导航点击“模型配置”。阅读原文不需要模型；识别人物、对白归属、局部复核和自动合并需要可用模型服务。

### 添加与管理

1. 填写配置名称、协议、API 根地址、模型名称和 API Key。
2. API 根地址不要包含具体的对话请求路径，按服务商提供的接入信息填写。
3. 测试连接并检查结果；连接测试可能产生少量费用。
4. 保存后，在处理页面选择这项配置。

已保存配置可编辑、删除或清除密钥。密钥不在页面回显；“仅本次会话”保存方式下，重启服务后需重新填写。

### 生成与思考设置

可调整最大输出 Token、随机性、采样范围和请求超时，并设置默认思考模式与强度。留空或选择服务默认时，由模型服务决定。

处理页的“沿用模型配置”使用这里的默认思考设置；处理页明确选择其他模式只影响该任务，不修改默认值。关闭思考时不使用强度。

本次 Token 上限留空不代表单次输出无限。思考可能占用输出预算；遇到正文为空或输出被截断，检查最大输出 Token、思考设置、超时和模型服务限制，不要只增加本次额度。

## 通用设置页

顶部导航点击“通用设置”。编辑先进入草稿，需要点击对应保存按钮；离开页面会丢弃未保存修改。

### 阅读显示

调整字号、行距、自动续读、默认候选引语和人物标注显示。这些设置不调用模型，也不改变导出文件的字号与行距。

“显示待确认对白标记（⚠）”默认关闭。开启并点击“保存阅读与处理设置”后，阅读和处理页预览中的待确认对白会显示 ⚠，包括未知说话人、模型校验警告或人工标记的对白；阅读时点击标记可查看并确认，处理页可前往待确认队列核对。已解决或已延后的记录不显示标记。设置保存在当前浏览器，保存后立即生效，无需重启，不影响导出；恢复阅读显示默认值会关闭该选项，仍需保存。

“双击目录章节名切换完成状态”默认关闭。开启并保存后，双击未处理章节标为已完成，再次双击改回未处理；处理中、排队、失败或已停止章节第一次双击也标为已完成。操作不删除正文和标注，但停止本章旧队列；标为完成不代表模型实际处理过。

### 人物资料更新

“允许后台人物识别更新人工姓名与说明”默认关闭。关闭时批量和自动处理保留人工资料；开启后新人物任务可按原文证据更新，模型误判也可能覆盖你的修正。手动修改和接受自动合并建议不受此开关限制。

### 章节处理过滤名单

“按章节名自动跳过处理”默认关闭。开启后，可在“过滤名单”中每行添加一个章节名或关键词，选择匹配方式，再点击“保存阅读与处理设置”。

- 完全匹配：“封面”只匹配完整标题“封面”。
- 包含匹配：“封面”也匹配“第一卷 · 封面”。默认提供封面、书名、制作信息、版权信息、简介、彩页、目录、插画和插图，可自由增删；空行会忽略。

命中名单的章节在目录显示“自动跳过处理”，单章人物分析、对白处理、批量及阅读时自动处理都不调用模型；强制重做也遵守名单。仍可阅读、手动修改人物或局部复核，不会删除已有标注或改变完成标记。要恢复处理，删除对应项或关闭过滤并保存。已启动批次及其恢复队列沿用启动时的名单。

开启过滤后，单章处理需先选择具体章节，不能使用跨章的自定义范围。匹配按目录显示的完整标题进行，不自动忽略卷名。

### 自动提前处理章节

开启后，按当前阅读章及设置的后续章节数自动估算和处理，不再逐次要求确认模型调用。先检查模型、思考、并发、复核和额度，再开启。

切换阅读章节时，新目标可加入现有队列，不必等上一批结束；已完成章节默认跳过。失败不会无限自动重试，可在阅读目录中重试，或按自动处理面板提示刷新额度并重试。停止后不再派发新任务，在途请求仍需收尾。

阅读显示、人物资料更新、章节过滤和自动处理配置，点击“保存阅读与处理设置”后生效，无需重启。

### 应用配置

可调整书库目录、端口、密钥保存方式、模型等待与重试、导入和 EPUB 限制。普通使用无需编辑 `.env`。

- 容量统一使用 MB，可填小数；1 MB = 1024 × 1024 字节。
- “保存应用配置”只保存，下次启动生效。
- “保存并重启”保存后重启服务，需先等待任务结束；当前启动方式不支持时，按提示手动重启。
- 更换书库目录不会搬迁书籍，新目录没有数据时会显示空书架。
- 改端口后需打开新地址。部分配置可能被启动方式锁定，请查看原因。

离线测试配置不代表真实模型能力，普通使用保持默认即可。

### 恢复默认值

各区域分别恢复，只修改该区域草稿，不自动保存或重启：

- 阅读显示：恢复字号、行距及显示、续读和双击选项。
- 人物资料更新：关闭后台更新人工资料。
- 章节过滤：恢复默认名单及包含匹配，并关闭过滤。
- 自动处理：恢复自动处理及本栏的模型、思考、并发、复核和额度，不删除模型账号。
- 应用配置：恢复未锁定的应用配置，可能改变书库目录或端口，不删除或搬迁书籍。

恢复后仍需点击对应保存按钮；应用配置需重启生效。

## 导出窗口

阅读页或“预览与处理”页点击“导出”。

1. 选择整本或指定章节。
2. 选择“颜色 + 编号”“仅颜色”或“仅编号”。
3. 选择“初读安全”或“重读”。初读安全不带入阅读位置之后才知道的标注，重读显示完整标注。
4. 选择 EPUB 或 HTML，查看样张及提示后生成。
5. 通过校验后下载。若提示标注已变化，重新预览和生成。

导出不调用模型，也不改写书籍。其他阅读器的字体、排版和颜色设置可能影响显示，不保证完全一致。

重新导入本应用导出的 EPUB，可恢复导出包含的人物、颜色标注和已处理章节状态，减少重复处理；未导出、未知或初读隐藏的标注不会恢复。书签及完整任务记录不随导出迁移，因此导出不能替代完整书库备份。

新导出的 EPUB 还会携带可完整核验的人物姓名、别名、说明、配色、确认来源和修改后的显示时点，模型确认不会变成人工确认。迁移完整人物资料建议选择整本：只导出部分章节时，依赖未导出章节的完整人物资料会跳过并提示数量。文件正文被修改或资料位置无法核验时，相应人物资料可能不能恢复，但不阻止正文导入；旧版导出文件仍可导入，能恢复的范围取决于文件实际包含的资料。

## 常见问题与安全提醒

- **读取失败**：查看具体错误，点击对应“重新读取”。正文缺失时需要找回书库文件或重新导入，反复处理不能修复原文缺失。
- **任务看起来不动**：先查看详情，确认是在排队、等待模型、额度不足还是失败，不要仅凭正文已有颜色判断完成。
- **人物归属不正确**：模型判断不是保证。优先人工更正或局部复核；泛称、复杂引用和缺少线索的对白可能仍需手动确认。
- **哪些操作花费 Tokens**：阅读、估算、预处理、书签、手动更正和导出不调用模型。人物分析、试运行、正式处理、局部复核、自动合并分析及连接测试会调用模型；失败请求也可能产生费用。
- **隐私与备份**：书籍保存在本机，但模型处理会把所需小说片段或人物资料发送给你选择的服务。应用没有账号系统或云端同步；升级、删除或大范围合并前，先停止任务并备份书库目录。
