# 评测配置

配置版本为2.0；用于开发评测，不是阅读页面设置。执行复用当前“整章识别人物 → 自动确认 → 对白窗口处理”流程，人物按章节顺序沿用。模型与生成参数由已保存的 --profile-id 指定，提示词采用当前实现，报告记录程序版本。

| 文件 | 策略 |
| --- | --- |
| b0.json | 离线显式归属规则，不调用模型 |
| b2.json | 当前章节流程，context-1，不额外复核 |
| b3.json | 当前章节流程，context-2，不额外复核 |
| b4.json | context-2，每窗口额外复核1轮，每轮覆盖全部对白 |

B1没有真正实现独立的场景开关，已删除其配置；历史报告不改写。

## 字段与额度

- config_version：必须为“2.0”。config_id、label、notes：配置身份与说明。
- strategy：rule_baseline / llm；context_policy：context-1 / context-2。
- reading_mode：initial / reread，传给任务及结果读取。
- budget.max_recheck_rounds：每窗口额外复核轮次，0关闭。不是条数；保留人工锁定，使用正常调度器的容量拆分及恢复检查点。
- budget.max_format_retries：对白输出校验失败的重试次数，0～5，默认1，不含首次调用；不是复核轮次。
- budget.max_input_tokens / max_output_tokens：每章对白任务的输入/输出额度；省略或null为不限。人物识别任务仅支持输入额度，沿用max_input_tokens。**不是全书总费用上限，也不能限制人物输出消耗。**
- inference_options.thinking_mode：default / disabled / enabled / adaptive；reasoning_effort：default / low / medium / high。人物与对白使用同一设置，default沿用模型配置。

不接受旧max_rechecks、scene_state、prompt_version、model字段或拼错的字段，避免记录但不生效。旧自定义配置需人工迁移为2.0：重新决定轮次数，不能把旧条数直接当轮次。

真实运行必须明确 --allow-live --profile-id，会产生费用并写入书库。每次使用新的专用书库及该库的模型配置；同一原始书籍已存在会拒绝运行，避免旧标注、人工资料和缓存污染对照。不能指向日常书库。失败显示LIVE_FAILED并保留已知费用和未知用量提示，不参与质量评分；未授权/未指定模型为NOT_RUN。没有文字的章节沿用应用跳过逻辑。

配置预算不能替代服务商费用限制。方法与隔离运行示例见[评测方法](../ablations.md)，历史证据见[报告说明](../reports/README.md)。

`ndr.evaluation.boundary_context` 是隔离的窗口原文对照准备器，不是这里的生产配置开关。它保留目标和候选人物，用有界连续原文补齐窗口两端；初读仍受可见范围限制，带旧引用提示或接力的输入会被拒绝，避免丢失或错用引用。策略版本、边界参数和任务指纹应进入调用账本依赖；仅准备原文不调用模型、不改书库，也不保证提高归属质量。

`ndr.evaluation.role_cues.RoleCueAdapter` 仅用于隔离的对话角色证据方向对照，不是生产设置。它在原有系统提示后追加通用核对规则，不改原文、人物引用、输出契约或生成参数；应包装账本适配器的外层，使实际追加规则后的请求进入缓存和计量。`role_cue_fingerprint` 将规则版本、内容和源任务纳入依赖指纹。该包装器不提供额外重试，不保证质量改善，仍须经过独立重复和端到端验证。

`ndr.evaluation.inert_nulls.InertNullAdapter` 是主动选用的隔离响应规范化：仅删除已知非发声类型中的 `character/basis/evidence=null`，不删除非空矛盾、空数组或未知字段，不改类型、人物判断或引用。最终编译校验仍严格执行。包装在账本外层，原始响应和失败用量仍保留；用 `normalization_fingerprint` 隔离规则版本，旧评测不能静默重新计为成功。离线规范化重放不是新模型效果，也不能证明人物归属更准。

同模块的 `RedundantFieldAdapter` 是另一个明确选择的策略：在上述空字段规则外，仅额外删除非发声分支中与本行 `kind` 完全相同的 `basis` 类型回显。其他非空矛盾仍拒绝，发声分支不修改；用独立 `kind_echo_fingerprint` 隔离缓存依赖，不改变旧适配器行为。两种策略的离线结果和真实模型结果应分别保留。

`ndr.evaluation.scoring.score_attribution_risks` 将标准身份等价映射限定在预测副本计分：风险检测必须使用人物目录与原始输出一致的原生 ID，禁止先改写输出人物 ID 再用旧目录检查证据。不属于原人物目录的改写 ID、未发送或重复的引用会被拒绝；缺失标签仍统计为缺失，不作为完整推理接受。匿名分组与显示名准确率需另行评估。修正评分命名空间只改变统计口径，不是新的模型效果，也不改变风险规则或生产归属行为。

`ndr.evaluation.type_basis_cues.TypeBasisCueAdapter` 是另一主动选择的提示消融：只补充真实发声/心理活动/引用，以及直接、指代、问答证据的区分，不改标签、引用、人物、原文范围或生成参数。包装在调用账本外层，使用 `type_basis_fingerprint` 隔离实际提示；返回和错误原样保留，不增加重试。它不自动在产品中启用，更少的 `DIRECT` 风险不能单独证明归属更准，须同时评估类型、身份与复核误改。

同模块的 `SpeechActivityCueAdapter` 单独比较类型说明，不追加证据类别规则：明确自言自语与叙述内实际发声仍可能是speech，但未说出口、纯措辞引用及沉默须分开核查，不自动修改类型。它使用独立的 `type_activity_fingerprint`；原 `TypeBasisCueAdapter` 默认行为与指纹不变。两种策略都不自动启用，实际类型质量和额外成本必须分别报告。

`ndr.evaluation.chain_risk.detect_chain_risks` 是独立主动选择的证据链风险检测：保留原生风险，补充被引用对白的开头称呼与回答候选冲突，并传播明确证据缺陷。称呼有例外，标记只表示需要核查，不自动分配回答者或修改结果；同称多身份不强判，边界与抽检标记不沿链传播。它只读本次已提供材料，不调用模型、不改变默认风险策略；调用者须用 `chain_risk_fingerprint` 隔离版本。更高错误召回可能同时接近全量复核，必须报告正确对白复核率、实际预算与纠正/误改，不能据此宣称省费或质量已经改善。

隔离整窗复核 `complete-linked-window-3` 按正文位置排列局部原文：对白与其间叙述保持阅读顺序，不先集中全部台词再放叙述；短引用、稳定引用及可见范围不变。候选结果合并后也保留原文顺序。版本和任务指纹须进入恢复依赖，旧账本不按新版本重跑；排序是输入组织修正，不是模型质量已经改善的证明。

`ndr.evaluation.turn_frames.TurnFrameAdapter` 是主动选择的受话对象提案消融：speech额外给当前候选中的受话对象及原文引用，无法确定时保持null。该字段仅作独立关系提案，不自动决定本句或下一句说话人。严格校验后仍使用原compact编译；原文、目标和生成参数不变，额外字段不进入产品输出。实际提示/原始提案由内层调用账本保存，作用域需用 `turn_frame_fingerprint` 隔离；已知格式失败的费用保留，原有有界重试可附带具体诊断，未知用量不继续调用。额外输出字段会消耗Tokens，字段合法不能证明人物归属正确，必须另做完整质量、成本和恢复对照。

隔离冷名单协议 `original-fact-roster-5` 区分原文姓名/别名与 `designation` 暂称。没有姓名时可以提出有原文角色依据的简短暂称，但“我/你/他”等人称词不能作为称呼。`evidence-index-2` 仅使用已到可见时点的事实；有姓名后优先姓名，暂称保留但不覆盖姓名，同称不自动合并人物。姓名/别名仍要求字面原文证据，暂称的语义是否正确须另做评估，不能把引用合法当作身份正确。新版本须新缓存依赖，旧事实及历史评测结果不改写；不是生产人物识别开关。 校验失败时会指出具体人物引用、事实种类、值和证据编号供模型纠错；不放宽显示名、字面证据或可见时点校验。 有已解析提案的校验失败复核会携带上次提案供模型对照纠错，并要求完整输出后重新严格编译；未解析响应不伪造提案，不自动删除错误事实或增加复核次数。
