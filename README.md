# 轻小说对话辅助阅读器

当前版本：`1.0.0`。

本地运行的轻小说阅读工具：用大语言模型识别对白中的说话人，以颜色和人物标签辅助阅读，并支持人工修正。

## 重点功能

- 导入 TXT / EPUB，保留正文、章节、注音与本地插图，检查目录和引号问题。
- 单章可选择多个窗口，批量可选章节范围；任务队列跨书籍追踪进度，支持持续入队、并发、Token 额度、停止与失败重试。
- 阅读时可自动提前处理后续章节，支持最后阅读位置、段落书签及初读 / 重读显示。
- 管理全书人物，编辑资料与颜色；模型合并先预览，选择后才执行。
- 待确认队列、人工更正与局部复核，保留人工锁定的对白归属。
- 导出带标注的 EPUB / HTML；本应用导出的 EPUB 可恢复所包含的标注和章节完成状态。

## 安装与启动

### Windows 免安装版

从 [Releases](https://github.com/19077frb/novel-dialogue-reader/releases) 选择可用版本，完整解压后双击 `NovelDialogueReader.exe`，无需安装 Python 或 Node.js。请保留配套文件夹。启动窗口保持运行，按 `Ctrl+C` 停止；只关闭浏览器不会停止服务。

支持 Windows 10/11 x64，目前未做代码签名。下载、升级和书库迁移见 [免安装版与发布指南](docs/RELEASING.md)。

### 从源码运行

环境：Windows 10/11、Python 3.11+、[uv](https://docs.astral.sh/uv/)、Node.js 22 / npm 10。

克隆后在项目根目录安装依赖：

```powershell
uv sync --project backend --all-groups
Push-Location frontend
npm ci
Pop-Location
```

双击 `start.bat`，就绪后打开 <http://127.0.0.1:8765>。停止时双击 `stop.bat`，或在启动窗口按 `Ctrl+C`；更换端口可运行 `.\start.bat 8800`。

## 快速使用

1. 在书架导入书籍，即可阅读原文。
2. 在“模型配置”填写服务地址、模型名称和密钥，测试并保存。
3. 进入“预览与处理”：单章先核对人物，再处理选定窗口；批量先估算再启动。
4. 返回阅读，检查人物标签，按需更正、收藏书签或导出。

应用配置在“通用设置”中修改并保存，无需创建 `.env`。

## 关键限制

- 模型处理会把所需正文或人物资料发送给所选服务，可能产生费用；判断仍需人工检查。
- 未设置 Token 额度不代表模型输出无限，失败请求也可能计费。
- 队列可在同一浏览器、同一服务地址恢复；关闭全部页面时，未派发任务暂不继续。服务重启导致的未知请求需检查，不自动重发。
- 源码默认书库位于仓库 `data/`；免安装版位于 `%LOCALAPPDATA%\NovelDialogueReader\data`。删除、升级或合并前建议备份。
- EPUB 复杂排版不保证完全还原；导出不包含书签和完整任务记录，不能替代书库备份。
- 当前面向本地单用户，没有账号系统或云端同步。
