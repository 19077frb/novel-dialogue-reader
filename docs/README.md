补充分类：

- `.env.example` 是源码配置示例，配置名/单位与实现一致，不包含密钥。
- `evaluation/schemas/`、清单和配置 JSON 是机器输入；生成类型和 OpenAPI按工具生成。
- 原创 TXT、EPUB/HTML、历史评测 JSON 是测试输入或证据，不是叙述文档，不因文案整理重写。
- `LICENSE` 是法律文本，不能作为普通说明任意改写。
- 内部影响报告、开发计划、工作记录和性能复盘保留在被忽略的 `docs/internal/`，不得提交，也不得由公开文档链接。

用户步骤以用户指南为主，技术行为以实现与契约为准，发布流程以工作流为准。新增文档先确定读者、职责和权威来源，尽量链接已有说明，不复制长篇内容。
