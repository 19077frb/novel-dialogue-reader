# 核心接口契约

机器可读的完整 API 定义见 [openapi.json](openapi.json)。本文件只保留跨模块必须遵守的语义约束。

## 响应与错误

成功响应使用统一数据包：

```json
{
  "data": {},
  "meta": {}
}
```

错误响应至少包含稳定错误码、可读消息和请求 ID。校验失败应指出具体字段或模型输出问题；任何响应都不能包含 API Key、授权头或未脱敏的提供方内容。

## 文本坐标

- 所有正文范围使用规范化全文的 Unicode 码点区间 `[start_cp, end_cp)`。
- 后端负责码点与源文件位置的映射。
- 前端处理 JavaScript UTF-16 索引时必须通过统一转换函数。
- 模型通过稳定的 quote/gap ID 引用内容，不能自行计算字符偏移。

## 原文和导入

- 原始文件和规范化正文不可变。
- TXT 必须严格解码；失败时可以返回候选编码预览，但不能把替换字符写入正文。
- EPUB 按 spine 顺序读取，只允许访问包内登记资源。
- 重新导入或更换编码应创建新版本，不能修改旧版本。

- 原文中的跨段未闭合 `“` 可在导入时生成段内虚拟 `”` 修复建议；扫描时应用，canonical 正文不可改写。
- 修复建议必须可查看、可编辑和可停用；重新检测或调整后只重建候选边界，不得清除或覆盖已有标注、对白归属和人工锁定结果。

## 人物和场景

- 章节人物记录跨场景身份，场景说话人记录当前对话参与者。
- `EXISTING` 只能引用当前场景已经声明的人物。
- 场景切换后，人物需要通过 `NEW` 和 `new_speakers` 在新场景重新声明。
- 已经由用户确认的人物姓名、身份和对白不能被模型输出覆盖。
- `UNKNOWN` 表示证据不足，不等于新人物。
- 场景切换必须有正文证据；普通叙述、心理描写或固定长度不能单独触发切换。

## 任务、缓存和幂等

- 创建任务的幂等键只能复用完全相同的请求摘要。
- 同一幂等键对应不同请求时返回冲突。
- 缓存键由语义输入生成，不包含任务 ID 或预览/正式处理标签。
- 已完成窗口可以复用；结果未知的远程调用需要用户明确选择是否重试。
- 暂停在窗口边界生效，恢复后不得重复提交已完成窗口。
- token 用量缺失时记录为未知，不能按零处理。

## 处理范围、模式和批量顺序

- `DELETE /api/books/{book_id}` 删除指定书籍及关联数据库记录，成功返回 204，不存在返回 404。若该书有 QUEUED/RUNNING/PAUSING 任务则返回 409；前端还需阻止当前会话正在运行的批量调度删除。独占书籍与导出目录移入数据目录 `trash/`，文件移动或数据库事务失败需回滚；文件占用或权限问题返回 503 和明确提示。不得按书名删除，也不得操作其他书籍或用户原始上传文件。应用内无法撤销，回收区仅保留文件，不保留数据库标注。

- 批量默认跳过 `dialogue_processed` 章节；显式开启强制重做时，预估与执行必须包含这些章节。`POST /api/jobs` 的 `force_reprocess=true` 跳过模型结果缓存（包括复核），但不解除人工标注锁定，也不改变请求幂等约束。

- 预览与处理入口必须先选择单章或批量模式，只展示当前模式的配置。批量模式必须独立提供模型、每窗口复核次数、token 上限和最大并发任务数。
- 单章窗口预览是本地只读计算，不调用模型，也不写入标注结果。
- 单章对白任务可以提交一个或多个窗口；窗口选择只限制对白归属推理，人物表分析始终使用完整章节正文。多个窗口受用户配置的并发上限约束，整章 token 上限按窗口估算比例分配。
- 批量人物分析必须严格按章节顺序执行，前章人物确认请求成功返回后才可启动下一章人物分析；人物任务之间不得并发。若前章人物识别或确认失败，记录失败并跳过其对白，随后可继续下一章；空人物名单不视为失败，跳过本章对白，不写入章节完成状态。已确认章节对白可与下一章人物分析并发，所有模型任务共享同一个并发上限。
- 单个章节或窗口失败只影响自身，不得把后续任务统一标为失败；用户主动停止或批次 Token 上限耗尽才触发安全停止。
- 并发窗口独立使用已确认的整章人物表，不要求消费其它并发窗口执行期间产生的临时场景状态；需要最强跨窗口连续性时并发数应设为 1。
- 批量运行期间，处理入口必须显示持久的任务进度（任务类型、章节、窗口和状态），并禁止切换模式或创建另一个任务。进度状态在应用内切换页面后仍须可恢复显示。
- 批次结束、失败或停止后，任务列表和具体错误仍须显示，配置入口恢复可用；应用内切换页面和模式不清除结果。当前会话保留最近一次批次，下一批启动替换列表，浏览器刷新或关闭后不保证恢复。
- 停止批量处理采用安全停止：排队任务不再派发，已经提交给提供方的请求允许收尾，且停止入口在批次终止前始终可见。
- 阅读目录的实时状态必须区分排队、人物识别、对白窗口进度、完成和失败/停止。任务行更新不得使阅读页重新请求目录或标注；窗口完成只刷新当前章标注，整章完成才刷新目录，短时间内的同类刷新必须合并。
- 目录的完成状态只读 `chapters.dialogue_processed`；旧任务状态由迁移一次性回填，读请求不得重复扫描任务历史。
- 书籍、目录和正文等只读查询只可对网络错误、限流和服务端临时错误做有限重试；最终失败必须展示具体原因和显式重试入口。
- 已确认的书籍人物可以作为后续章节的人物上下文，但不能替代对当前章节人物的重新分析。
- 批量 token 预估必须在正式启动前完成。设置上限时，用量未知不能视为零继续执行。
- 并发拆分任务不能直接宣称整章完成；只有本章全部外层候选对白都有当前标注后，覆盖校验接口才能写入已处理状态。
- 调大 token 上限只更新当前批次的限制并保留已消耗量，不得重建或重跑任务；额度刷新操作可以重置当前批次的额度计数，但不能删除已有处理结果。

## 模型输出

- 模型必须返回符合 schema 的 JSON。
- JSON 解析、字段约束、目标覆盖、引用完整性和场景状态全部由后端校验。
- 只允许修复不会改变语义的确定性错误。
- 格式重试和语义复核均受次数与预算限制。
- 证据不足的结果进入待确认队列。

## 人工更正

- 人工操作不调用模型。
- 更正以追加历史记录的方式保存，并支持有版本约束的撤销。
- 旧版本提交返回冲突，不能静默覆盖较新的修改。
- 更正可能使同一窗口或场景的其它自动结果失效。
- 被用户锁定的结果是后续处理的权威输入。

## 导出

- 导出基于不可变原文和冻结标注快照。
- 导出过程不调用模型，也不覆盖源文件。
- 未处理、未知或失效对白保留原文，不添加错误标签。
- EPUB 导出可以携带版本化的本地标注清单；重新导入时只恢复清单中与章节及对白原文匹配的可见标注，匹配失败不得阻断正文导入。
- 标注清单必须记录已完整处理的章节；回导后目录和批量任务都以该状态为准，默认不得再次调用模型处理这些章节；仅用户显式开启强制重做时可重新处理，仍保留回导锁定标注。
- 回导恢复的不同人物身份不能仅因显示名称相同而合并，恢复结果必须锁定，后续自动处理不得覆盖。
- EPUB 不包含脚本或远程资源；HTML 应可离线打开。
- 相同快照、格式和样式的请求可以复用已有产物。

## 安全

- 服务默认只监听本机回环地址。
- 模型密钥只进入系统凭据库或会话内存。
- 原文、数据库、导出文件和日志保存在 `NDR_DATA_DIR`，不得提交到 Git。
- 日志、任务错误和调试片段必须脱敏。
